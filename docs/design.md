# TYT 디자인 가이드 (초안)

여유 계산과 상태 구간의 원본은 `../tyt-be/docs/product.md`. 이 문서는 그것을 화면에 옮기는 방법만 적는다. 색 값과 글꼴은 합의 전 제안이다.

## 콘셉트: 출발이 가까워질수록 화면이 외출복을 입는다

- 화면의 주인공은 **출발까지 남은 분** 숫자 하나다.
- 출발이 가까워질수록 바탕이 맑은 하늘색 → 코발트 → 밤색으로 점점 짙어진다. 급함을 빨간색이 아니라 **진하기**로 알린다.
- 따뜻한 색(귤)은 출발 시각이 지났을 때만 켜진다.

## 원칙

1. **상태 색은 출발 조회 화면에만 쓴다.** 바탕 전체를 상태 색으로 칠하는 화면은 이 화면 하나다. 기록·일정 만들기는 밝은 바탕에 잉크로만 그린다.
2. **버튼과 선택 상태는 잉크로 칠한다.** 코발트·귤 버튼을 만들면 상태 색의 뜻이 흐려진다.
3. **분으로 말한다.** 시각(08:52)은 아래 카드에 보조로 둔다.
4. **조회 기준 시각을 늘 보여준다.** 조회할 때 계산하는 서비스라 "08:22 기준"과 새로고침을 둔다.

## 컬러

### 상태 척도

왼쪽에서 오른쪽으로 출발이 가까워진다. 구간은 product.md의 상태 구간을 따른다.

| 이름 | 값 | 상태 | 바탕 위 숫자 / 글자 |
| --- | --- | --- | --- |
| 하늘 | `#E8F0FA` | 준비 시간 초과 | 코발트 `#2F55C8` / 잉크 `#101B3B` |
| 짙은 하늘 | `#D9E6F7` | 15분 ~ 준비 시간 | 코발트 / 잉크 |
| **코발트 (아이덴티티)** | `#2F55C8` | 5–14분 | 흰색 / 흰색 |
| 밤 | `#101B3B` | 0–4분 | 흰색 / 흰색 |
| 밤 + 귤 숫자 | `#101B3B` | −1 ~ −2분 | 귤 `#FF8A4C` / 흰색 |
| 귤 | `#FF8A4C` | −3분 이하 | 잉크 / 잉크 |

- **아이덴티티 컬러는 코발트 `#2F55C8`.** "이제 움직이자"는 순간의 색이다. 로고, 앱 아이콘, 스플래시에 쓴다.
- 보조 글자는 밝은 바탕에서 `#5A6B8C`, 코발트 위에서 `#C9D6FA`, 밤 위에서 `#9DAAD0`, 귤 위에서 `#5A2E12`.

## 타이포그래피

세 글꼴 모두 SIL Open Font License 1.1이다. 앱에 넣어 배포하고 상업적으로 써도 무료다. 모두 Google Fonts에서 받을 수 있다.

| 글꼴 | 역할 | 크기 / 굵기 |
| --- | --- | --- |
| **함렛 Hahmlet** | 출발까지 남은 분 숫자, 상태 문구, 화면 제목 | 숫자 108 / 700, 문구 22 / 500, 제목 24 / 700 |
| **고딕 A1 Gothic A1** | 목록, 입력칸, 버튼, 안내 문장 | 본문 15 / 400, 항목 이름 15 / 700, 보조 12 / 400 |
| **레드햇 모노 Red Hat Mono** | 시각, 소요 시간, 눈금 | 13 / 500, 눈금 10 / 400 |

- 함렛은 획 끝이 부드러운 현대 명조라, 다정한 존댓말 문구가 딱딱하지 않다.
- 레드햇 모노에는 한글이 없다. "대중교통 38분" 같은 한글은 고딕 A1로 대체된다.

## 로고

### 앱 아이콘

| 항목 | 값 |
| --- | --- |
| 바탕 | 하늘 `#E8F0FA` |
| 글자 | 밤 `#101B3B`, 소문자 `tyt` |
| 글꼴 | Bricolage Grotesque 800, 자간 −0.02em |
| 글자 크기 | 아이콘 한 변의 42.5% |
| 모서리 | 한 변의 27.5% |
| 테두리 | 안쪽 1px `rgba(16, 27, 59, 0.08)` |

- 하늘은 여유가 가장 넉넉할 때(준비 시간 초과)의 바탕색이다. 앱을 열기 전부터 여유로운 첫 화면을 떠올리게 한다.
- 테두리는 밝은 배경화면에서 하늘색 바탕이 묻히지 않게 하려고 넣는다.
- Bricolage Grotesque는 SIL OFL 1.1 무료 글꼴이고 로고에만 쓴다. 앱 화면 안의 글자에는 쓰지 않는다.
- 워드마크(가로 로고)는 아직 정하지 않았다.

## 출발 조회 화면 구성

위에서 아래로 다음 순서로 둔다.

1. **상단 줄**: 일정 이름, 도착 목표 시각.
2. **히어로**: "출발까지" → 큰 숫자 + "분" → 상태 문구 → 보조 한 줄. 보조 줄은 15분 ~ 준비 시간 구간이면 "준비는 천천히 시작하면 돼요", 출발 시각이 지났으면 "예상 도착 09:34". 보조 줄이 없어도 높이는 비워 둬서 문구가 바뀔 때 레이아웃이 튀지 않게 한다.
3. **분 눈금자**: 30분부터 −5분까지 1분에 눈금 하나. 15분·5분·출발에 긴 눈금과 라벨을 둔다. 남은 분은 진하게, 지난 분은 흐리게 칠하고, 지금 위치에 점을 찍는다. 상태 구간 경계가 눈금으로 보인다.
4. **카드**: 출발 시각 · 이동 수단과 소요 시간 · 도착 시각.
5. **하단**: "08:22 기준"과 새로고침 버튼.
